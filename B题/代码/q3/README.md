位 0--7 是零件 `x1..x8` 检测，位 8--10 是半成品 `y1..y3` 检测，位 11 为最终成检 `yf`，位 12--14 是半成品拆解 `z1..z3`，位 15 是最终拆解 `zf`。结果核算单位为每最终交付一件合格成品，售价只计一次。

程序采用局部闭环方程/树状递推的等价精确求解，**不**为每条策略显式构建完整多状态转移矩阵。局部方程保留“直接子件真实质量、检测结果和坏品回流”的必要条件：拆解只把同一批直接子件送回本节点的检测流程，不重置为新件。安全回流的几何循环以 `(1-p)V=r` 精确求值，等价于对应可达 Markov 奖励链的局部消元。若已知坏节点拆解后存在未检直接子件，则为可达闭类并标记 `NON_ABSORBING`。`SUCCESS_EXACT` 仅表示闭环方程可解并最终吸收，不表示一次装配良率为 100%。

全部 65536 条固定策略均被评价；“精确最优”只指题设参数和这个固定策略域。模型假设零件独立、检测完美无损、节点装配缺陷仅在直接子件均良时发生。状态规模经局部核化简后很小，使用稠密 `numpy.linalg.solve`，不强制引入稀疏框架。
