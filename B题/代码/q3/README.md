位 0--7 是零件 `x1..x8` 检测，位 8--10 是半成品 `y1..y3` 检测，位 11 为最终成检 `yf`，位 12--14 是半成品拆解 `z1..z3`，位 15 是最终拆解 `zf`。结果核算单位为每最终交付一件合格成品，售价只计一次。

程序采用后序局部核 + 树状闭环方程的等价精确求解，**不**为每条策略显式构建完整多状态转移矩阵。拆解只把同一批直接子件送回本节点的检测流程，不重置为新件：若该子件的检测决策为 1，回收后会再次检测并再次计费，但不重复采购；已知合格半成品回收后只重检半成品本身，不重检其内部零件或重复装配。安全回流以 `(1-p)V=r` 精确求值；每次运行还会以独立的二零件显式 Markov 链交叉核对四类策略的吸收性、成本和事件次数。若已知坏节点拆解后存在未检直接子件，则为可达闭类并标记 `NON_ABSORBING`。`SUCCESS_EXACT` 仅表示闭环方程可解并最终吸收，不表示一次装配良率为 100%。

全部 65536 条固定策略均被评价；“固定 65536 策略域内精确最优”只在全域枚举、真实局部方程残差和显式链交叉验证均通过时使用。模型假设零件独立、检测完美无损、节点装配缺陷仅在直接子件均良时发生。状态规模经局部核化简后很小，使用稠密 `numpy.linalg.solve`，不强制引入稀疏框架。
