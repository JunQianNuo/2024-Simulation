## 1. 已确认模型—算法接口

| 问题 | 模型规定 | 本阶段算法职责 | 不得混淆 |
|---|---|---|---|
| Q1 | Q1-M6：在 AQL/LTPD 双风险约束下最小化灰区最坏 ASN | Q1-A2 求精确二项基线，以截尾 SPRT 生成边界并用路径 DP 校准风险 | SPRT/DP 是求解算法，$p_1$ 与风险约束属于模型 |
| Q2 | Q2-M2：吸收 Markov 奖励闭环利润优化 | Q2-A1 生成策略状态链、检查吸收性、求奖励方程并比较 16 种策略 | 枚举和线性求解不是模型 |
| Q3 | Q3-M3：装配树—吸收 Markov 闭环利润优化 | Q3-A1 缓存树状态核、精确评价 65536 种策略 | 树和物料守恒属于模型，后序遍历属于算法 |
| Q4 | Q4-M4 联合选择抽样对象、停止时刻和生产策略；Q4-M2 是终止价值，Q4-M3 是稳健审计 | Q4-A3 精确 DP 或 KG/rollout；Q4-A1 计算终止后验价值；Q4-A2 联合构集与最坏搜索 | Bellman 目标和抽样成本属于模型；后向递推、求积/MC、KG 与搜索属于算法 |

算法选择遵循六条门禁：

1. **有限策略空间优先精确搜索**，不以 GA/SA 替代可完成的全枚举；
2. **每次策略评价必须可复核**，利润同时输出采购、检测、装配、拆解、调换和重生产分账；
3. **统计误差与数值误差分开**，Q1 精确尾概率/路径风险、Q4 CS 覆盖、Monte Carlo 误差和线性方程残差分别记录；
4. **失败关闭（fail closed）**，非吸收、病态、未收敛、超时不能被当作普通有限利润；
5. **最优性称谓与证据一致**：全枚举完成才称“固定策略域精确最优”；稳健内层未认证时只称“数值最坏解”。
6. **抽样以决策价值而非统一精度驱动**：Q4 不因某个参数区间较宽就机械续抽，只有预计能改善最终净利润时才检测；KG/rollout 未与精确 DP 校准时不得称最优。

## 2. 统一输入、输出与代码接口

### 2.1 输入数据结构

#### Q1 抽样流

```text
SampleRecord:
  item_id: str
  t: int
  is_defective: bool
  batch_id: str | null
  observed_at: datetime | null
```

算法只需要累计量 $(t,K_t)$，其中 $K_t$ 为前 $t$ 件中的次品数；原始记录仍需保存，以审计重复、漏记和停止后的违规追加观测。

#### Q2 六种情形

```text
scenario_id,
p1, buy_cost1, test_cost1,
p2, buy_cost2, test_cost2,
pf, assembly_cost, final_test_cost, sale_price,
replacement_loss, disassembly_cost
```

要求概率在 $[0,1]$，成本非负，货币单位统一为元/件。

#### Q3 装配树

```text
Node:
  node_id: str
  node_type: leaf | assembly | root
  defect_rate: float
  buy_cost: float | null
  test_cost: float
  assembly_cost: float | null
  disassembly_cost: float | null

Edge:
  parent_id: str
  child_id: str
  quantity: int = 1
```

根节点另存 `sale_price` 与 `replacement_loss`。载入后必须检查有且仅有一个根、无有向环、每个非根节点只有一个父节点，以及父节点的直接子件集合与题图一致。

#### Q4 抽样证据

为避免与检测决策 $x_v$ 混淆，抽样证据统一记为 $(N_j,K_j)$：

```text
SamplingEvidence:
  parameter_id: str
  N_j: int
  K_j: int
  sampled_object: str
  conditioning: str
  stopping_rule: str
  sample_test_cost: float
  sample_preparation_cost: float = 0
  sample_consumption_cost: float = 0
  destructive: bool = false
  batch_id: str | null
```

内部节点的 $K_j/N_j$ 必须对应“直接子件均合格条件下的装配失败率”；若条件不符，算法返回 `INVALID_CONDITIONING`，禁止直接代入。未来一次有效观测的边际成本定义为 `sample_test_cost + sample_preparation_cost + sample_consumption_cost`，其中 preparation 必须包含为估计条件装配率而筛出合格子件的费用；所有抽样、制样、消耗和切换成本必须有限且非负，否则返回 `INVALID_DATA`。它们与生产策略中的常规全检成本分账，禁止重复扣除。

序贯设计另需：

```text
SequentialSamplingConfig:
  prior_a: dict[parameter_id, float]
  prior_b: dict[parameter_id, float]
  max_additional_samples_H: int
  total_sampling_budget: float | null
  per_parameter_caps: dict[parameter_id, int] | null
  switch_cost: matrix[parameter_id, parameter_id] | null
  exact_dp_max_states: int
  rollout_depth_L: int
  rollout_paths_M: int
  value_tolerance: float
  mc_max_samples: int
```

题面未给的先验强度、预算、破坏成本和切换成本必须出现在情景配置中，不能隐藏在代码常量里。若样本量预先固定，`stopping_rule=fixed_n`；若由 Q4-A3 自适应停止，必须保留每一步的选择概率、对象、结果和停止原因，供 Q4-A2 选择正确的置信构集方法。

### 2.2 统一输出对象

PolicyEvaluation:

  event_counts: dict[str, float]

## 4. Q1-A2：精确二项基线 + 风险校准截尾 SPRT + 精确路径 DP

> [!important] 重构口径
> Q1-M6 规定的是“两质量点、双风险约束下尽可能少抽检”的优化问题；Q1-A2 才是求解流程。旧 Q1-A1 的双单侧 CS 针对单阈值任意停止推断，不能继续充当新模型的主算法。旧代码与旧结果必须标记为 `STALE_MODEL_RESULT`，不得只换标题后复用。

### 4.1 输入、输出与可行性契约

| 类别 | 内容 |
|---|---|
| 设计输入 | $p_0=0.10$；$p_1\in\{0.12,0.13,0.15,0.20\}$，主情景 $p_1=0.13$；$\alpha=0.05$；$\beta=0.10$；截尾倍率 $\kappa\in\{1,1.25,1.5,2\}$ |
| 数据假设 | $X_i\overset{\mathrm{i.i.d.}}{\sim}\operatorname{Bernoulli}(p)$；检测完美、无损；批内参数恒定 |
| 决策输出 | 固定样本基线 $(n_F,c_F)$；序贯边界 $(a_t,r_t)$；截尾 $N_{\max}$；终端截断数 $c_N$ |
| 性能输出 | 两端点精确风险、OC 曲线、灰区 ASN 上确界及位置、P50/P90/P99、最大样本量、相对固定基线的 ASN 节省率 |
| 硬门禁 | $P_{p_0}(R)\le0.05$，$P_{p_1}(A)\le0.10$；$N_{\max}\le\kappa n_F$；每条路径二元终止：$P_p(A)+P_p(R)=1$ |
| 最优性口径 | 边界族搜索与 $p\in[p_0,p_1]$ ASN 上确界都完成认证时称“族内最优”；否则按证据降为网格内/局部可行 |

`p1` 不是由样本反推的自由变量。若把它与边界一起优化，算法会倾向选择更远、更容易区分的劣质点，从而用较少样本换取过宽容的质量要求。因此只能把 $p_1$ 当工程输入并做敏感性分析。

### 4.2 最小固定样本精确二项基线

固定抽样方案在第 $n$ 件后统计次品数 $K_n$，当 $K_n\le c$ 时接收，否则拒收。两端点风险为

$$
\alpha_F(n,c)=P_{p_0}(K_n>c)
=1-F_{\operatorname{Bin}(n,p_0)}(c),
$$

$$
\beta_F(n,c)=P_{p_1}(K_n\le c)
=F_{\operatorname{Bin}(n,p_1)}(c).
$$

按 $n=1,2,\ldots$ 递增搜索。对每个 $n$，先取使 $\alpha_F\le0.05$ 的最小整数 $c$，再检查 $\beta_F\le0.10$；首次通过即为 $(n_F,c_F)$。主计算使用 `scipy.stats.binom.sf/cdf`，不得用 `1-cdf` 计算极小上尾；再以 log-PMF 累加或 `mpmath` 独立复核。

以下只是**固定基线单元测试 oracle**，不是新序贯方案的最终结果：

| $p_1$ | $n_F$ | $c_F$ | $\alpha_F$ | $\beta_F$ |
|---:|---:|---:|---:|---:|
| 0.12 | 2096 | 232 | 0.0493657550 | 0.0995398380 |
| 0.13 | 968 | 112 | 0.0486497073 | 0.0997558579 |
| 0.15 | 368 | 46 | 0.0496448526 | 0.0999328161 |
| 0.20 | 109 | 16 | 0.0432080762 | 0.0990770489 |

实现若不能在 $10^{-9}$ 内复现该表，禁止进入序贯优化。Duan & Zhang（2026）的 $n=271/165$ 是单侧筛查规模，其表4在 $p=0.13$ 的拒收率仅约 47%；这类方案必须在本门禁下判定为“不满足 $\beta=0.10$”，不能误作双风险基线。

### 4.3 Wald SPRT 仅用于生成初始边界

针对简单端点 $H_0:p=p_0$ 与 $H_1:p=p_1$，累计对数似然比为

$$
\ell_t
=K_t\log\frac{p_1}{p_0}
 +(t-K_t)\log\frac{1-p_1}{1-p_0}.
$$

Wald 初始阈值取

$$
A_0=\frac{\beta}{1-\alpha},
\qquad
B_0=\frac{1-\beta}{\alpha},
\qquad A_0<1<B_0.
$$

于是 $\ell_t\le\log A_0$ 时接收，$\ell_t\ge\log B_0$ 时拒收，其余继续。令

$$
d=\log\frac{p_1(1-p_0)}{p_0(1-p_1)},
\qquad
b=\log\frac{1-p_1}{1-p_0},
$$

则初始整数边界为

$$
a_t^{(0)}=\left\lfloor\frac{\log A_0-tb}{d}\right\rfloor,
\qquad
r_t^{(0)}=\left\lceil\frac{\log B_0-tb}{d}\right\rceil.
$$

Wald 阈值忽略离散越界和有限截尾效应，**不能直接当作风险已经达标**。代码必须在精确 DP 后校准；凡仅输出 Wald 近似风险的实现都返回 `RISK_NOT_EXACTLY_VERIFIED`。

### 4.4 强制二元截尾与精确路径 DP

对 $t<N_{\max}$，候选规则由接收边界 $a_t$ 和拒收边界 $r_t$ 决定；到达 $N_{\max}$ 后，用整数 $c_N$ 强制终止：

$$
K_{N_{\max}}\le c_N\Rightarrow A,
\qquad
K_{N_{\max}}>c_N\Rightarrow R.
$$

因此不存在未决状态。对任意真实次品率 $p$，令 $q_t(k;p)$ 为时刻 $t$ 决策后仍继续且累计 $k$ 个次品的概率质量，$q_0(0;p)=1$。到达下一状态前

$$
\widetilde q_{t+1}(k;p)
=(1-p)q_t(k;p)+p\,q_t(k-1;p).
$$

按照边界把 $\widetilde q_{t+1}$ 分流到 $A$、$R$ 或下一层继续状态；在 $N_{\max}$ 按 $c_N$ 全部分流。由此精确得到

$$
P_p(A),\quad P_p(R),\quad
\operatorname{ASN}(p)=\sum_{t=0}^{N_{\max}-1}\sum_kq_t(k;p),
$$

以及停止时间分布和分位数。概率守恒要求

$$
P_p(A)+P_p(R)=1\pm10^{-12}
$$

（在极端长边界下可放宽到 $10^{-10}$，但必须记录）。性能评价禁止用 Monte Carlo 替代此有限状态递推。

### 4.5 风险校准与灰区最坏 ASN 优化

候选规则写为

$$
\pi(N_{\max},c_N,h_A,h_R),
$$

其中 $h_A<h_R$ 是校准后的对数似然阈值；Wald 的 $(\log A_0,\log B_0)$ 只是搜索起点。阈值只在越过某个可达状态分数 $\ell_t(k)$ 时改变整数动作表，因此搜索应在这些**离散断点**上进行，而不是对无效的小数网格盲扫。

对每个 $(p_1,\kappa)$ 执行：

1. 求精确固定基线 $(n_F,c_F)$，把“直到 $n_F$ 才按 $c_F$ 决策”加入 $\kappa\ge1$ 的候选集，保证至少有一个可行方案；
2. 以 Wald 边界为中心生成可达 LLR 断点，按风险单调方向扩展 $h_A,h_R$；
3. 对 $N_{\max}=1,2,\ldots,\lfloor\kappa n_F\rfloor$ 与可行 $c_N$ 做分层搜索；
4. 先用端点 DP 计算 $\alpha(\pi)=P_{p_0}(R)$、$\beta(\pi)=P_{p_1}(A)$，不达双风险门禁者立即剪枝；
5. 对可行候选计算
   $$
   J(\pi)=\sup_{p\in[p_0,p_1]}\operatorname{ASN}(p;\pi);
   $$
6. 以 $J$ 最小为主，依次以更小 $N_{\max}$、更小端点最大 ASN、端点平均 ASN 破同；
7. 在完整 OC 网格重新核验单调性和风险，最后才写入成功状态。

#### 灰区 ASN 上确界认证

固定边界后，存活到时刻 $t$ 且累计 $k$ 个次品的路径条数是确定整数，因此 $\operatorname{ASN}(p;\pi)$ 是次数不超过 $N_{\max}$ 的 Bernstein 型多项式。上确界搜索不能只看 $p_0,p_1$。至少执行：

1. 首批点包含 $p_0,p_1$ 与零漂移点
   $$
   p^\dagger=-\frac{b}{d},
   $$
   其中 $b,d$ 见 4.3；
2. 在 $[p_0,p_1]$ 自适应细分，用高精度函数值和 Bernstein/区间包络给每个子区间的 ASN 上下界；
3. 直到全局上界与当前最好下界之差
   $$
   U_J-L_J\le\epsilon_{\rm ASN},
   \qquad
   \epsilon_{\rm ASN}=\max(10^{-6},10^{-8}n_F);
   $$
4. 保存最大点区间、上下界和细分日志。

完成“全部预声明边界断点 + 灰区上确界认证”才返回 `SUCCESS_EXACT_FAMILY`。若边界只在 Wald 邻域局部搜索，返回 `SUCCESS_LOCAL_CALIBRATION`；若边界搜索完整但灰区只做离散网格，返回 `SUCCESS_GRID_OBJECTIVE`。后两者都不能写“族内最优”。

### 4.6 $p_1$—截尾倍率双重敏感性

独立运行

$$
p_1\in\{0.12,0.13,0.15,0.20\},
\qquad
\kappa\in\{1,1.25,1.5,2\}.
$$

主结果固定 $p_1=0.13,\kappa=1$。$p_1=0.13$ 是 Duan & Zhang（2026）的可行动恶化基准；0.12 检查更严格分辨要求，0.15/0.20 检查放宽 LTPD 后的省样本效果。$\kappa$ 则量化“最大可能抽检数”与“灰区最坏 ASN”的交换。每档必须报告：

- 固定 $(n_F,c_F)$ 与序贯 $(N_{\max},a_t,r_t,c_N)$；
- $\alpha,\beta$ 的精确值及风险裕度；
- 灰区 ASN 上确界 $[L_J,U_J]$、最大点区间、端点 ASN 与 P50/P90/P99；
- 相对固定基线的 ASN 节省率，以及相对 $\kappa=1$ 增加的最大抽检数；
- OC 曲线 $P_p(A)$，特别标出 $P_{p_0}(A)\ge0.95$、$P_{p_1}(A)\le0.10$；
- 推荐是否随 $p_1$ 或 $\kappa$ 改变。

若 $p_1-p_0$ 缩小时样本量陡增，这是质量分辨率的统计代价；若增大 $\kappa$ 只能微幅改善 ASN，则推荐 $\kappa=1$，不要为极小平均收益承担更长尾。论文不能只展示样本最少的 $p_1=0.20$ 或最大 $\kappa$。

### 4.7 复杂度、并行与缓存

设待评价候选数为 $G$，核验参数点数为 $P$。单候选的三角状态递推上界为 $O(N_{\max}^2)$，滚动概率向量为 $O(N_{\max})$；故

$$
T=O(GPN_{\max}^2),
\qquad
M_{\rm work}=O(N_{\max}).
$$

边界只依赖 $(p_0,p_1,h_A,h_R)$，应按哈希缓存；风险筛选阶段只跑 $p_0,p_1$ 两点，完整 OC 与分位数只对可行前沿候选计算。候选之间确定性并行，归并时按 `(J_upper,Nmax,endpoint_max_ASN,endpoint_mean_ASN,boundary_hash)` 固定排序，避免 worker 完成顺序改变推荐。

### 4.8 基准、性质测试与失败路径

| 检查 | 通过标准 | 失败处理 |
|---|---|---|
| 固定基线 oracle | 复现 4.2 表，风险差 $\le10^{-9}$ | 检查 CDF/SF 方向、整数截断数和尾概率实现 |
| Wald 初始化 | 允许不达标，但必须被精确 DP 识别 | 不得把近似阈值直接发布；进入风险校准 |
| 概率守恒 | 所有 OC 网格点 $P(A)+P(R)=1\pm10^{-10}$ | 定位边界重叠、漏分流或截尾遗漏 |
| 双风险 | $P_{p_0}(R)\le0.05$ 且 $P_{p_1}(A)\le0.10$ | `INFEASIBLE_RISK_PLAN` 或继续校准 |
| OC 单调性 | $P_p(A)$ 随 $p$ 非增，容差 $10^{-10}$ | 检查边界单调性和状态索引 |
| 二元终止 | 截尾后继续质量为 0 | `TERMINAL_MASS_REMAINS`，结果禁用 |
| 灰区目标认证 | $U_J-L_J\le\epsilon_{\rm ASN}$ | 未达标则 `SUCCESS_GRID_OBJECTIVE`，不得称族内最优 |
| 截尾倍率 | $N_{\max}\le\lfloor\kappa n_F\rfloor$ | 超限候选直接判不可行 |
| 非法早停 | 决策后不得读取后续样本 | 审计日志失败，整次运行无效 |
| 模型版本 | 配置含 `model_id=Q1-M6`、`algorithm_id=Q1-A2` | 旧 `summary.json` 标记 `STALE_MODEL_RESULT` |

最终 Q1 结果不得出现“未决率”“低未决方案”或旧 Pareto 二目标；若出现，说明代码仍在执行 Q1-M5/A1。

## 5. Q2-A1：16 策略精确枚举 + 吸收链奖励求解

### 5.1 输入与输出

| 类别 | 内容 |
|---|---|
| 输入 | 表 1 单个情形的 13 个字段，四位策略 $d=(x_1,x_2,x_r,y_r)$ |
| 输出 | 16 个策略的状态、利润、成本分账、事件次数、吸收裕度；最优策略集合 |
| 精确性口径 | 对已定义的 16 个固定策略全枚举；不扩张到历史自适应策略 |

### 5.2 状态图生成

算法只生成从初始订单可达的状态，不建立无用笛卡尔积。状态至少包含：

$$
s=(\ell,z_1,z_2,k_1,k_2,o_1,o_2),
$$

其中 $\ell$ 为流程位置，$z_i$ 为真实质量，$k_i$ 为已知信息，$o_i$ 为新购/拆回来源。状态采用不可变 tuple 并哈希；广度优先展开所有概率非零的转移，直到成功交付吸收态。

对每个瞬态状态记录：

- 到其他瞬态状态的概率；
- 直接进入成功吸收态的概率；
- 本步采购、检测、装配、拆解、调换和其他成本；
- 各类事件计数。

### 5.3 吸收性双重检查

1. **图检查**：在可达有向图上找强连通分量；若存在不含吸收泄漏的闭合可达分量，则标记 `NON_ABSORBING`；
2. **数值检查**：对通过图检查的瞬态矩阵 $P_d$ 计算最大模特征值或收敛上界，并记录吸收裕度
   $$
   \delta_d=1-\rho(P_d)>0.
   $$

图检查是有限状态链吸收性的主判据；$\varepsilon_\rho=10^{-10}$ 只是数值预警阈值，不是额外可行性条件。若 $0<\delta_d\le\varepsilon_\rho$，标记 `NEAR_NONABSORBING` 并用高精度复核，不能把有限但巨大期望的策略直接删掉；若数值谱半径与图检查冲突，先返回检查冲突并重算。不允许通过人为截断循环得到有限利润。

### 5.4 多右端奖励求解

不显式计算 $(I-P_d)^{-1}$。令

$$
A_d=I-P_d,
$$

把成本和所有事件计数向量拼成多右端矩阵

$$
B_d=[\mathbf c_d,\mathbf g_1,\ldots,\mathbf g_m].
$$

对 $A_d$ 只做一次稀疏 LU：

$$
A_dX_d=B_d.
$$

由初始状态对应行得到总成本和事件次数，利润为 $S-C(d)$。线性残差要求

$$
r_d=
\frac{\|A_dX_d-B_d\|_\infty}
{\|A_d\|_\infty\|X_d\|_\infty+\|B_d\|_\infty}
\le10^{-10}.
$$

失败时依次做行列缩放、迭代改进、稠密高精度对照；仍失败则返回 `ILL_CONDITIONED`，不参与最优比较。

### 5.5 策略比较与并列处理

完成 16 个策略后选择最大期望利润。若利润差满足

$$
|\Pi(d_i)-\Pi(d_j)|
\le10^{-8}\max\{1,|\Pi(d_i)|,|\Pi(d_j)|\},
$$

保留为并列最优集合；论文可再以“检测/拆解动作更少”作为透明的运营次级准则，但不能修改主目标值。

### 5.6 复杂度、预期范围与失败路径

若瞬态状态数为 $S_2$、非零元数为 $Z_2$，最坏稠密上界为 $O(16S_2^3)$，实际使用稀疏 LU，复杂度由填充量决定。Q2 规模很小，目标是正确而非追求元启发式速度。

预期检查：

- 一次装配成功率为 $(1-p_1)(1-p_2)(1-p_f)$，题给六种情形约在 0.512–0.8574；
- 期望采购、检测、装配、拆解、调换次数均非负；
- 期望利润不超过一次售价；
- 情形 6 拆解成本为 40，拆解价值应受到明显压制；
- 任一分账之和必须等于总成本，误差不超过 $10^{-8}$ 元。

## 6. Q3-A1：装配树局部核缓存 + 65536 策略精确搜索

### 6.1 输入与输出

| 类别 | 内容 |
|---|---|
| 输入 | 8 叶、3 半成品、1 成品的 AND 装配树与节点参数；16 位策略 |
| 输出 | 65536 个策略完整评价、全局最优固定策略集合、策略排名与分账 |
| 精确性口径 | 必须评价全部 $2^{16}$ 个固定策略；只在一般大树扩展时才允许近似回退 |

### 6.2 策略编码

固定使用位序：

```text
bits 0..7   : 零件1..8是否检测
bits 8..10  : 半成品1..3是否检测
bit 11      : 成品是否检测
bits 12..14 : 半成品1..3是否拆解
bit 15      : 成品是否拆解
```

编码表写入结果元数据，禁止在不同函数中重新定义位序。

### 6.3 后序局部状态核

对装配树做一次后序遍历。每个节点 $v$ 的局部状态核记录：

$$
K_v^{\pi_v}:
(\text{输入物料/质量/信息状态})
\longrightarrow
(\text{输出状态、概率、成本、事件计数}),
$$

其中 $\pi_v$ 是节点及其直接子树的局部决策签名。相同局部签名只计算一次。题给三个半成品子树分别只有有限种局部策略，缓存后再在根节点组合，避免为每个全局策略重复生成相同子树。

缓存只能合并“未来转移与奖励完全一致”的状态；仅概率接近或期望相同但信息不同的状态不得合并。每个核保存版本、子树哈希、参数哈希与状态字典。

### 6.4 全策略评价

1. 生成 0–65535 的全部策略整数并解码；
2. 查询/生成三个半成品子树核；
3. 在根节点组合成可达稀疏 $P_d$ 与多右端奖励矩阵；
4. 执行与 Q2 相同的 SCC+谱半径吸收检查；
5. 稀疏 LU 一次求全部成本与事件次数；
6. 写入分区 Parquet；
7. 所有 worker 完成后按策略整数排序归并，选择最大利润。

任务切片固定，例如每块 256 个策略；随机调度不能改变排序、并列规则或浮点归并次序。Ray/Dask 负责分布式执行，Numba 负责状态核与策略位运算。

### 6.5 正确性基准

| 基准 | 要求 |
|---|---|
| 树拓扑 | 半成品 1/2/3 分别接收 3/3/2 个零件，根接收 3 个半成品 |
| 无检测一次良率 | $0.9^{12}\approx0.2824$ |
| 物料守恒 | 每次父节点装配消耗每个直接子件各 1；拆解返回每个直接子件各 1 |
| 子树退化 | 只保留一个二零件子树时，与 Q2 对应策略结果一致 |
| 全策略覆盖 | 唯一策略 ID 数恰为 65536，无重复、无遗漏 |
| 精确最优口径 | 所有可吸收策略成功评价，或明确列出失败策略并完成高精度复核 |

### 6.6 复杂度与失败路径

设全策略数 $D=65536$，一次缓存后策略组合与求解成本为 $C_{\rm kernel}$：

$$
T=O(D\,C_{\rm kernel}),
$$

空间主要来自核缓存、单个策略稀疏矩阵和结果表；worker 不同时保留全部策略矩阵。

主线不因运行时间改用 GA/SA。若分布式任务失败，先重试确定性分片；仍失败则扩容。只有当题目推广到远大于当前 16 位策略时，才进入分支定界或近似算法，并另行降低最优性称谓。

## 7. Q4-A1：终止价值的全策略后验计算（确定性求积 + Monte Carlo）

Q4-A1 现在服务于 Q4-M4 的停止价值

$$
G(s)=\max_{d\in\mathcal D}\mathbb E_s[\Pi(d;\mathbf p)],
$$

同时也在实际停止后生成完整 Bayesian 风险报告。**它只负责给定 belief state 的后验积分和生产策略比较，不决定下一件抽检谁。**

### 7.1 后验与统一接口

对每个参数保存

$$
p_j\mid N_j,K_j
\sim
\operatorname{Beta}(a_j,b_j),\qquad
a_j=a_{j0}+K_j,\quad b_j=b_{j0}+N_j-K_j.
$$

接口为

```text
terminal_value(
    belief_state,
    production_problem,     # Q2 or Q3
    policy_space,
    integration_config,
    evaluator_version
) -> TerminalValueResult
```

`TerminalValueResult` 至少含 $G(s)$、$d_B^*(s)$、各策略后验期望利润、数值误差、最优概率、遗憾和缓存键。belief state、生产评价器、策略位序或积分配置任一变化，都必须产生新缓存键。

主线仍做两组透明先验敏感性：

- Uniform：$(a_{j0},b_{j0})=(1,1)$；
- Jeffreys：$(a_{j0},b_{j0})=(1/2,1/2)$。

若以题给比例 $\widetilde p_j$ 构造先验，则必须显式给出有效强度 $\tau_j$，使用
$a_{j0}=\tau_j\widetilde p_j,\ b_{j0}=\tau_j(1-\widetilde p_j)$，并与上述弱先验对照。任何一种都不是题面事实。

### 7.2 Q4-Q2：确定性 Beta 求积作为精确 DP 内核

Q2 只有 $J=3$ 个质量参数和 16 个生产策略。为避免 Bellman 递推被嵌套 MC 噪声污染，主线对每个独立 Beta 后验使用 Gauss–Jacobi 求积，形成张量节点：

$$
\mathbb E_s[\Pi(d;\mathbf p)]
\approx
\sum_{r_1=1}^{q}\cdots\sum_{r_J=1}^{q}
\left(\prod_{j=1}^J w_{jr_j}\right)
\Pi\!\left(d;p_{1r_1},\ldots,p_{Jr_J}\right). \tag{A1-1}
$$

执行契约：

1. 用 SciPy `roots_jacobi` 生成与 $p^{a_j-1}(1-p)^{b_j-1}$ 匹配的节点和归一化权重；
2. 从 $q=8$ 开始，依次检查 $q=12,16,24,32,\ldots$；
3. 只有当所有竞争策略的价值变化、前两名利润差变化和 $G(s)$ 变化均不超过 `value_tolerance`，且最优策略连续两级不变，才返回 `VALUE_INTEGRATION_CONVERGED`；
4. 用 `scipy.integrate.nquad`、稀疏网格或高精度 MC 对随机抽取的 belief states 独立复核；
5. 达到 `q_max` 仍不稳定时返回 `VALUE_INTEGRATION_NOT_CONVERGED`，Q4-A3 不得把该状态当成精确终端值。

因此“Q2 精确 DP”准确含义是：**有限动作/状态递推完整，后验积分达到声明的确定性数值容差**，而不是声称浮点积分绝对无误差。

### 7.3 Q4-Q3：全策略共同随机数 / 随机化 QMC

Q3 有 65536 个固定生产策略和 $J=12$ 个参数，张量求积不可行。对同一组基础均匀数 $\mathbf u^{(b)}$，在不同 belief state 下用 Beta 逆 CDF 变换

$$
p_j^{(b)}(s)=F^{-1}_{\operatorname{Beta}(a_j,b_j)}(u_j^{(b)}),
$$

再令

$$
Y_b(d;s)=\Pi(d;\mathbf p^{(b)}(s)).
$$

同一状态内所有策略、相邻后验状态 $s,T_j^1s,T_j^0s$ 以及 KG 的不同候选动作共享基础 $\mathbf u^{(b)}$，以配对方式估计价值差。主线用 Owen-scrambled Sobol 序列并采用不少于 8 个独立 scramble 估计数值误差；普通伪随机 MC 作为独立复核。

不得仅保留 nominal top-$K$。每个后验样本必须覆盖全部 65536 个策略，除非某策略已被**对所有相关状态有效的利润上界**证明不可能进入竞争集。单纯按当前均值排名筛选会漏掉“在某次观测后翻盘”的策略，禁止用于 Q4-A3。

探索配置从以下值起步，并由误差而非算力决定停止：

```text
base_seed = 2024
confirm_seed = 12024
scrambles = 8
B0_per_scramble = 1024
batch_size_per_scramble = 1024
Bmax_total_Q2_MC_oracle = 262144
Bmax_total_Q3 = 131072
epsilon_profit = max(0.01, 0.001 * sale_price)
epsilon_prob = 0.005
stable_checkpoints = 3
```

每批更新所有策略的后验均值、配对利润差、最优概率和遗憾。探索样本只用于选择候选策略和决定计算是否继续；最终报告使用预先固定、相互独立的确认 scramble/seed。确认批次推翻排序或误差未达标时返回 `MC_NOT_CONVERGED`，输出近优策略集合，不强行给唯一最优。

### 7.4 输出、误差与分账

对停止时选择的策略及竞争策略至少报告

$$
\widehat{\mathbb E}_s[\Pi_d],\quad
\operatorname{SE}_{\rm num}(\Pi_d),\quad
\Pr_s(d\text{ 最优}),
$$

$$
\Pr_s(\Pi_d<0),\quad
\mathbb E_s[R_d],\quad
Q_{0.05}(\Pi_d),Q_{0.50}(\Pi_d),Q_{0.95}(\Pi_d).
$$

必须区分：

- 后验分布区间：参数未知导致的 Bayesian 不确定性；
- 求积误差或 MC/RQMC 标准误：数值计算误差；
- 选择偏差：在同一批噪声估计上取最大值导致的乐观偏差，以独立确认批次缓解；
- 过去抽样成本：不进入 $G(s)$ 的生产策略排序，但进入总净利润；
- 未来抽样成本：由 Q4-M4/A3 在行动价值中扣除，Q4-A1 不再重复扣。

### 7.5 复杂度与缓存

若策略数为 $D$、参数样本/求积节点数为 $B$、单次策略评价成本为 $C_{\rm eval}$，一次终止价值计算为

$$
T=O(BD C_{\rm eval}).
$$

Q4-A3 会在大量相邻 belief states 上调用 Q4-A1，因此必须缓存：

1. `(belief_state, evaluator_hash, integration_hash)` 对应的策略价值向量；
2. 固定参数块下的局部状态核；
3. 基础 Sobol/伪随机数，而不是直接缓存某一后验的 Beta 样本；
4. 独立探索与确认结果，禁止混用。

缓存命中只能降低时间，不能绕过当前容差检查。若内容哈希不一致，返回 `STALE_VALUE_CACHE` 并重算。

## 8. Q4-A2：固定/自适应联合置信集 + 稳健内层搜索

Q4-A2 是停止后的**频率学审计算法**。它不决定 Bayesian 抽样动作，也不要求 Q4-M4 为所有参数机械追求同一精度。

### 8.1 先识别抽样设计，再构造联合集合

设 Q2 有 $J=3$ 个质量参数，Q3 有 $J=12$ 个。主报告使用 90% 联合集合，95% 作保守敏感性：

$$
\alpha_{\rm total}\in\{0.10,0.05\},\qquad
\alpha_j=\frac{\alpha_{\rm total}}{J}.
$$

**情形 A：预先固定每个参数的样本量。** 对 $K_j$ 个次品、$N_j$ 个样本，用双侧 Clopper–Pearson 区间

$$
\mathcal C_j^{\rm fixed}
=
\left[
B^{-1}\!\left(\frac{\alpha_j}{2};K_j,N_j-K_j+1\right),
B^{-1}\!\left(1-\frac{\alpha_j}{2};K_j+1,N_j-K_j\right)
\right], \tag{A2-1}
$$

并对 $K_j=0$ 或 $K_j=N_j$ 使用标准端点约定。

**情形 B：Q4-A3 根据历史数据自适应选择对象或停止。** 对每个参数的本地样本时钟构造 Howard 同族 Bernoulli confidence sequence

$$
\mathcal C_{j,t_j}^{\rm seq}=[L_{j,t_j},U_{j,t_j}],
$$

再以 Bonferroni 得到

$$
\mathcal U=\prod_{j=1}^J\mathcal C_j. \tag{A2-2}
$$

只要每一步在看到当前结果**之前**选择抽样对象，且各对象的 Bernoulli 条件模型成立，本地 time-uniform CS 才可用于数据依赖的跨对象分配与停止。若日志缺失、抽样对象在看到结果后补记或制样条件变化，返回 `INVALID_ADAPTIVE_SAMPLING_LOG`。

固定样本不得无故换成更宽的 CS；自适应样本也不得事后假装固定 $N$ 使用普通区间。两者都不根据已看到的利润结果重新分配 $\alpha_j$。

### 8.2 单调性先认证

对每个固定生产策略 $d$，先检查能否证明

$$
\frac{\partial\Pi(d;\mathbf p)}{\partial p_j}\le0,
\qquad \forall \mathbf p\in\mathcal U,\ j=1,\ldots,J.
$$

认证分三层：

1. **结构耦合证明**：固定相同随机数，增加缺陷只能增加重试、报废、调换或保持不变，不得凭直觉忽略回流状态；
2. **自动微分反例搜索**：在角点、中心和 Sobol 网格检查 Jacobian 符号；只能发现反例，不能单独构成证明；
3. **区间导数认证**：用区间算术证明整个盒内导数上界不大于零。

若全部维度完成认证，则

$$
\Pi_{\min}(d)=\Pi(d;U_1,\ldots,U_J).
$$

若只认证部分参数，只把这些维度固定在上端点，其余维度继续全局搜索。

### 8.3 未获单调证书时的内层搜索

对剩余 $r$ 个维度依次执行：

1. 枚举 $2^r$ 个角点；
2. 用 SHGO 搜索连续内部极小值；
3. 用不少于 10 个固定种子的 differential evolution 独立互证；
4. 对最终竞争策略做区间分支定界，直到
   $U_d^{\rm inner}-L_d^{\rm inner}\le\epsilon_{\rm robust}$；
5. 外层仍覆盖 16/65536 个生产策略。只允许用严格上下界淘汰，不允许 nominal top-$K$ 删除。

默认配置：

```text
SHGO: sampling_method="sobol", n=8192, iters=5
DE: seeds=2024..2033, popsize=max(20, 10*r), maxiter=3000
    tol=1e-9, atol=1e-10, polish=true
Interval BnB: epsilon=max(0.01, 0.001*sale_price)
              max_boxes=10_000_000
              max_walltime=6 h / competitive policy
```

严格区分：

- `ROBUST_CERTIFIED`：内层有效上下界 gap 达标；
- `ROBUST_NUMERICAL`：角点、SHGO、DE 一致但无严格证书；
- `ROBUST_UNCERTIFIED`：搜索分歧或预算耗尽。

Q4-M3 默认只输出审计报告。Bayesian 策略与稳健策略不同不是算法失败；应报告最坏利润改善、后验期望利润机会成本和策略切换原因。只有企业预先声明利润底线时，审计结果才成为硬门禁。

### 8.4 必须输出的审计信息

- 固定/自适应抽样识别结果及日志完整性；
- 每个 $\mathcal C_j$、联合覆盖档位和 Bonferroni 分配；
- Bayesian 终止策略 $d_B^*$ 的最坏利润与最坏参数；
- 稳健策略 $d_R^*$、内层上下界和认证状态；
- $d_R^*$ 相对 $d_B^*$ 的后验期望利润损失；
- 90% 与 95% 集合的策略稳定性；
- 抽样成本分账；不得在 $\Pi_{\min}$ 与总利润中扣两次。

## 9. Q4-A3：序贯价值信息求解——Q2 精确 DP，Q3 KG/rollout

### 9.1 算法契约与 Bellman 动作值

输入为初始 belief state $s_0$、追加检测上限 $H$、货币预算 $B$、各对象边际成本 $c_j^{\rm s}$、可选切换成本 $c_{o,j}^{\rm sw}$、Q2/Q3 生产评价器和 Q4-A1 终止价值接口。无硬货币预算时取 $B=+\infty$。

在状态 $(s,h,o,b)$，停止动作值为

$$
Q_{\rm stop}(s)=G(s).
$$

检测对象 $j$ 的动作值为

$$
Q_j(s,h,o,b)=
-c_j^{\rm s}-c_{o,j}^{\rm sw}
+\mu_j(s)V_{h-1}(T_j^1s,j,b-c_j^{\rm s}-c_{o,j}^{\rm sw})
+[1-\mu_j(s)]V_{h-1}(T_j^0s,j,b-c_j^{\rm s}-c_{o,j}^{\rm sw}). \tag{A3-1}
$$

Q4-A3 负责计算/近似这些动作值，返回下一动作以及达到停止时的生产策略。抽样数量是政策运行结果，不是预先拍定的同一 $n$。

### 9.2 Q4-Q2：记忆化后向 DP

Q2 的 $J=3$ 较小。状态键使用“各参数新增坏/良计数、剩余期数、上一检测对象”，即

```text
state_key = (
  add_bad[1:J],
  add_good[1:J],
  h_remaining,
  budget_remaining_or_infinite,
  last_parameter_or_none
)
```

进入 DP 前将全部货币按声明精度缩放为整数（如分）或使用精确 `Decimal`；禁止以未经规范化的二进制浮点余额作为缓存键。

递推步骤：

1. 调用 Q4-A1 的确定性求积后端计算并缓存 $G(s)$；
2. 若 $h=0$、预算不足、所有对象达到上限或 EVPI 上界不超过最便宜可行动作成本，立即保存停止动作；
3. 对每个可抽对象计算式 (A3-1)；
4. 取最大动作；若多个动作在 `value_tolerance` 内等价，依次优先“停止、无切换、成本低、参数 ID 小”，保证结果确定；
5. 保存价值、动作、Bellman residual 和两个子状态，形成可审计的策略 DAG；
6. 从 $s_0$ 做前向遍历，输出实际观察到的路径；另用后验预测模拟给出整个政策的期望检测次数和分配。

忽略硬货币预算、切换成本和对象上限时，新增计数总和不超过 $H$ 的 belief states 数量上界为

$$
\binom{H+2J}{2J};
$$

若记录上一对象，再乘至多 $J+1$；启用硬预算/切换成本后还要乘可达的离散预算余额数。因此 J=3 仍会随 $H/B$ 快速增长。`exact_dp_max_states` 是内存/时间保护值；超过前应先利用以下**有证据的剪枝**，不能任意截状态：

- $\operatorname{EVPI}(s)\le\min_j(c_j^{\rm s}+c_{o,j}^{\rm sw})$ 时停止；
- 预算或单对象上限使动作不可行；
- 对称参数/成本/生产影响完全一致时合并状态；
- 价值上下界已证明某动作不可能胜出。

仍超限则返回 `VOI_DP_STATE_LIMIT`，转入 rollout 并降低最优性称谓。成功状态为 `SUCCESS_VOI_DP_TOL`，含义是“给定 $H/B$、先验、成本和生产策略域内，Bellman 递推完整且终止积分达到容差”。

### 9.3 Q4-Q3：成本敏感的一步 KG

Q3 的 12 参数使精确 DP 不可行。一步净 Knowledge Gradient 定义为

$$
\operatorname{KG}_j(s,o)
=
\mu_j(s)G(T_j^1s)
+[1-\mu_j(s)]G(T_j^0s)
-G(s)-c_j^{\rm s}-c_{o,j}^{\rm sw}. \tag{A3-2}
$$

它直接衡量“多看一个参数结果后，允许重新选择生产策略”带来的期望净利润，而不是熵下降或区间宽度。基策略为：

$$
j^*=\arg\max_j\operatorname{KG}_j(s,o);
\quad
\max_j\operatorname{KG}_j\le0\ \Rightarrow\ \text{停止}.
$$

Frazier 等的 KG 最优性定理针对正态信念；式 (A3-2) 是 Beta–Bernoulli、非线性装配利润下的一步 VOI 迁移，**只能称 myopic policy**。

### 9.4 rollout 改善短视性

以成本敏感 KG 为 base policy，对每个候选首动作 $a\in\{\text{stop},1,\ldots,J\}$，用共同随机数模拟 $M$ 条后验预测路径，向前看 $L$ 步：

$$
\widetilde Q_L(a;s)
=
\mathbb E_s\!\left[
-\sum_{\ell=1}^{T_a}
(c_{j_\ell}^{\rm s}+c_{j_{\ell-1},j_\ell}^{\rm sw})
+G(S_{T_a})
\mid A_0=a,\ \text{后续采用 base policy}
\right]. \tag{A3-3}
$$

实施要求：

1. 不同首动作共享基础参数样本、预测 Bernoulli 随机数和 Q4-A1 的 Sobol 样本；
2. 对动作价值差用配对批次/独立 scramble 估计置信半宽；
3. 逐级检查 $L=1,2,3,\ldots,L_{\max}$，报告 rollout 深度敏感性；
4. 对竞争动作使用独立确认批次，避免用同一噪声同时选动作和报价值；
5. 缓存重复 belief state；可用价值函数回归/神经近似加速，但其训练集、外推误差和精确 Q2 对照必须单列，不能替代原始 rollout 校验。

rollout 返回 `SUCCESS_VOI_ROLLOUT` 时，只表示预设模拟误差和校验通过，不表示 Q3 全局最优。

### 9.5 物理抽样停止规则

**精确 DP：** 若 $Q_{\rm stop}\ge\max_j Q_j$（含确定性容差），立即停止。

**KG/rollout：**

- 若所有动作相对停止的配对价值差上置信界 $\le0$，返回 `STOP_NO_POSITIVE_NET_VOI`；
- 若某动作下置信界 $>0$ 且领先其他动作的差异达到容差，执行该对象；
- 若区间跨过 0 或多个动作无法区分，先增加**计算样本** $M/B$，而不是立即增加物理检测；
- 达到计算上限仍不清楚，返回 `VOI_MC_NOT_CONVERGED` 并列出“停止/继续”的价值区间；不得伪装成确定建议；
- 达到硬上限 $H$ 或预算时返回 `SAMPLING_HORIZON_REACHED`，强制进入 Q4-M2。

后验最优概率、某参数置信宽度和遗憾都作为报告指标，不默认设为额外硬停止条件。这样避免为了不影响生产决策的参数继续付费。

### 9.6 主伪代码

```text
observe initial counts -> build belief s
while remaining_budget and h > 0:
    G(s) = terminal_value(s)
    if problem == Q2 and state_budget_allows:
        action = exact_dp_policy[s, h, last]
    else:
        action_values = rollout_or_KG(s, h, last)
        refine numerical samples until action-value tolerance or cap
        action = certified_best_action_or_ambiguous
    if action == STOP:
        break
    test selected parameter before seeing outcome
    record object, cost, conditioning and outcome
    update Beta sufficient statistics
    h -= 1
d_final = argmax_d E[profit(d, p) | s]
run robust audit with fixed-n intervals or time-uniform CS as appropriate
report sampling cost + production cost + net profit exactly once
```

### 9.7 验证与基准

Q4-A3 必须通过以下层级：

1. **恒等式**：$V_h(s,o,b)\ge G(s)$，$V_h(s,o,b)\ge V_{h-1}(s,o,b)$，且 $V_h-G\le\operatorname{EVPI}(s)$；
2. **退化检验**：$H=0$、预算为零或检测成本极大时立即停止并复现 Q4-M2；
3. **微型枚举**：$J\le2,H\le4$ 时枚举全部观察树，与 memoized DP 逐状态一致；
4. **Q2 oracle**：在多组先验/成本/$H/B$ 上比较精确 DP、一步 KG、rollout；报告净利润 gap 和动作一致率；
5. **分配基线**：与不追加抽样、每参数固定相同 $n$、按后验方差/成本的固定分配比较；
6. **独立外层仿真**：先从先验/指定真实参数生成物理观察路径，再执行政策和生产，估计净利润、检测次数、选错策略概率和遗憾；
7. **错设敏感性**：改变先验强度、参数相关性、检测成本、破坏成本、切换成本和 $H/B$；
8. **分账审计**：路径累计检测成本 + 终止后的生产成本 = 报告总成本，任何负成本或重复扣除均失败。

### 9.8 必须输出

- Q2：完整或可压缩的最优策略 DAG、初始动作、$V_H$、Bellman residual、状态数与缓存命中率；
- Q3：每一步 KG/rollout 动作价值、配对误差、深度 $L$、路径数 $M$、选择/停止理由；
- 两问共同：实际路径检测分配、期望总检测次数、分位数、EVSI/NVSI/EVPI、终止生产策略、后验遗憾、抽样与生产净利润分账；
- 基线比较：相对固定均匀抽样和不抽样的净利润提升及额外计算成本；
- 最优性标签：`exact-DP-to-tolerance`、`validated-rollout`、`myopic-KG` 或 `ambiguous`，不得混写。

### 9.9 复杂度

Q2 精确 DP 的粗上界为

$$
O\!\left(
(J+1)\binom{H+2J}{2J}\,
J\,C_G
\right),
$$

其中 $C_G$ 是一次终止价值求积成本。Q3 一次 $L$ 步 rollout 决策约为

$$
O(M\,L\,J\,C_G),
$$

而 $C_G$ 内又含 $D=65536$ 个生产策略评价，因此必须使用状态缓存、共同随机数、批量加速和分布式执行。资源不足只能减少经验证的情景范围或降低结论称谓，不能把未校准 KG 写成精确最优。

## 10. 六个算法的通用契约

### 10.1 Q1–Q3 确定性算法

| 项目 | Q1-A2 | Q2-A1 | Q3-A1 |
|---|---|---|---|
| 输入 | Bernoulli 流、$p_0,p_1,\alpha,\beta$ | 表1情形、4位策略 | 装配树、16位策略 |
| 输出 | 固定基线、二元边界、双风险、OC、灰区最坏 ASN/分位数 | 16 策略利润与分账 | 65536 策略利润与分账 |
| 初始化 | 精确二项 $(n_F,c_F)$ + Wald LLR 边界 | 初始待交付订单 | 后序树核缓存 |
| 停止 | 预声明边界族搜索完成并通过精确风险门禁 | 16 策略完成 | 65536 策略完成 |
| 随机性 | 无 | 无 | 无 |
| 失败 | 高精度复算；风险不达标回退固定方案 | 修复状态图，不截断伪解 | 重跑分片/扩容，不先上 GA |

### 10.2 Q4 三算法

| 项目 | Q4-A1 终止价值 | Q4-A2 稳健审计 | Q4-A3 序贯 VOI |
|---|---|---|---|
| 输入 | belief state、先验、生产评价器、积分容差 | 原始计数、抽样设计日志、联合错误预算、评价器 | $s_0,H,B$、抽样/切换成本、Q4-A1、生产评价器 |
| 输出 | $G(s)$、生产策略、后验概率、遗憾、数值误差 | 联合集合、最坏利润/参数、稳健策略、认证状态 | 下一动作/停止、政策 DAG 或 rollout 轨迹、净 VOI、检测分配 |
| 主方法 | Q2 Gauss–Jacobi 求积；Q3 全策略 CRN/RQMC | fixed-$n$ 精确区间或 sequential CS；单调性/全局搜索 | Q2 memoized DP；Q3 KG + rollout |
| 停止 | 积分/MC 容差达标或返回不收敛 | 单调证明或内层 gap 达标/预算耗尽 | Bellman 停止；净 VOI 非正；硬预算/期界 |
| 随机性 | Q2 无；Q3 固定 Sobol scramble/seed | DE 固定种子；SHGO/区间法确定性 | Q2 无；Q3 固定 CRN，独立确认 |
| 最优性 | 后验积分到容差 | certified/numerical/uncertified | Q2 finite-horizon exact-to-tolerance；Q3 validated approximation |
| 失败 | 扩大求积/MC，输出近优集合 | 扩大认证预算或降低称谓 | 超状态限转 rollout；动作值不清楚则返回 ambiguous |

### 10.3 求解器专项检查

当前主线没有把 Q1–Q4 写成 LP/MIP，因此 `incumbent/bound/MIP gap/IIS` 不适用。Q3 的固定策略最优性来自全集覆盖；Q4-A3 的 Bellman residual、Q4-A1 的积分误差、Q4-A2 的区间内层 gap 是三种不同量，禁止统称“求解器 gap”。

### 10.4 日志与复现

每次运行必须写入：

- Git/代码版本、模型报告版本与所有配置文件哈希；
- Python、Julia/区间工具、依赖库、操作系统和硬件；
- 输入文件哈希、批次与制样条件；
- 策略位序、状态 schema、生产评价器版本；
- belief state、先验来源、有效强度、抽样成本口径；
- 物理抽样路径：每步可选集合、所选对象、结果、成本和停止原因；
- 数值随机种子/Sobol scramble、批次大小、worker 数；
- 求积阶数、MC/RQMC 误差、Bellman residual、rollout 深度；
- 缓存键、命中率和失效记录；
- 运行时间、峰值内存、中间产物路径与状态码。

## 11. 复杂度总表与主要瓶颈

| 算法 | 时间复杂度主项 | 空间主项 | 瓶颈 | 主要加速 |
|---|---|---|---|---|
| Q1-A2 | $O(GPN_{\max}^2)$ | 工作 $O(N_{\max})$ | 边界候选与精确端点 DP | 风险剪枝、断点索引、候选并行 |
| Q2-A1 | $O(16\,C_{LU}(S_2))$ | 单策略稀疏矩阵 | 状态定义正确性 | 一次 LU 多右端 |
| Q3-A1 | $O(65536\,C_{\rm kernel})$ | 局部核 + 单策略矩阵 | 全策略组合与求解 | 子树核缓存、Numba、Ray |
| Q4-A1/Q2 | $O(q^J D C_{\rm eval})$, $J=3,D=16$ | 求积节点与价值缓存 | 多 belief states 重复积分 | Gauss–Jacobi、状态缓存 |
| Q4-A1/Q3 | $O(BD C_{\rm eval})$, $D=65536$ | 批次利润/流式统计 | 全策略×后验样本 | CRN/RQMC、JAX、Zarr、集群 |
| Q4-A2 | $O(D C_{\rm inner})$ | 搜索队列与区间盒 | 12维连续最坏搜索 | 单调性认证、角点、区间并行 |
| Q4-A3/Q2 | $O((J+1){H+2J\choose2J}J C_G)$ 基础上界 | belief state DAG | $H/B$ 与切换状态导致组合爆炸 | EVPI 剪枝、memoization、对称合并 |
| Q4-A3/Q3 | $O(MLJ C_G)$ / 决策 | rollout 路径与价值缓存 | 路径×动作×终止价值嵌套 | CRN、缓存、GPU/TPU、Ray |

效果优先不等于无限计算。任何预算耗尽都必须留下误差界和状态码：Q2 超状态限可降为 rollout；Q3 未校准不得称精确；稳健搜索无证书只能称 numerical。

## 12. 适应性、扩展性与局限性

### 12.1 规模与精度适应性

| 算法 | 本题规模 | 扩展策略 | 精度口径 |
|---|:---:|---|---|
| Q1-A2 | ✅ 有限状态可完成 | 更窄 $p_1-p_0$ 时用活动前沿、风险剪枝和区间 ASN 认证 | 路径风险、灰区 ASN 与截尾分别核验 |
| Q2-A1 | ✅ 16 策略 | 历史自适应生产决策需另建 MDP，不能沿用 16 策略称谓 | 全枚举 + 线性代数误差 |
| Q3-A1 | ✅ 65536 固定策略 | 位数翻倍时转严格分支定界/树 DP | 全策略覆盖才称固定域精确 |
| Q4-A1 | Q2 ✅；Q3 需集群 | Q2 提高求积阶数；Q3 用 RQMC、流式全策略与缓存 | 后验不确定性和数值误差分开 |
| Q4-A2 | ⚠️ 12维认证昂贵 | 先证明单调维度再降维 | 有内层上下界 gap 才称 certified |
| Q4-A3 | Q2 中小 $H/B$ ✅；Q3 精确 DP ❌ | Q2 以状态限决定 DP/rollout；Q3 使用 KG/rollout/ADP | Q2 exact-to-tolerance；Q3 validated approximation |

### 12.2 局限性登记

| # | 局限性 | 可能影响 | 阶段4/6缓解 |
|---|---|---|---|
| L1 | 独立缺陷率、恒定参数和状态定义可能错设 | 数值精确但语义错误 | 手算微型链、事件追踪、跨批漂移检验 |
| L2 | Q1 的 $p_1$ 不是题面数据 | 样本量受工程偏好驱动 | $p_1$ 全流程敏感性与公开 OC/ASN |
| L3 | $\rho(P_d)$ 接近 1 | 利润排名对浮点敏感 | SCC、条件数、残差和高精度复算 |
| L4 | Q3 精确仅针对固定 16 位策略 | 结论被误写成所有动态政策最优 | 在策略编码和结论中重复边界 |
| L5 | Q4 无真实 $(N_j,K_j)$、预算和完整抽样成本 | 无唯一最优检测次数 | 参数化接口；所有数值标企业数据或情景 |
| L6 | Beta 先验小样本敏感 | 抽样对象、停止和生产策略改变 | Uniform/Jeffreys/有效强度敏感性 |
| L7 | 独立 Beta 忽略供应商/批次相关 | VOI 与风险被低估或高估 | 相关扰动、层次模型情景 |
| L8 | KG 一步短视，rollout 有有限深度 | Q3 净利润低于未知最优政策 | 用 Q2 精确 DP 校准，多深度/多 seed 外层验证 |
| L9 | Q4-A3 嵌套 Q4-A1 数值误差 | 错选抽样对象或过早停止 | 配对 CRN、误差传播、独立确认和 ambiguous 状态 |
| L10 | Bonferroni 矩形集合保守 | 稳健利润偏低 | 90/95% 双档、相关集合扩展、只作审计 |
| L11 | 自适应抽样日志或条件制样不完整 | Bayesian likelihood 与 CS 均失效 | 强制 schema、时间戳、对象先选后观测 |
| L12 | 抽样与生产检测成本可能重复 | 净利润系统性偏低 | 独立成本账户和逐件追踪测试 |
| L13 | 题面无抽样耗时/产能 | 不能优化交付周期 | 有时间数据后升级 SMDP/调度 |
| L14 | 期界 $H$/预算 $B$ 是资源边界 | 太小会截断有价值信息 | 检查 $V_H$ 与初始动作随 $H/B$ 的稳定性 |
| L15 | 检测可能破坏或样件不可回用 | 边际成本被低估 | `destructive` 标志与消耗成本敏感性 |

## 17. 阶段3推荐结论

> [!summary] Q4 重构后的模型—算法组合
> 1. **Q1**：精确二项固定基线 + 风险校准截尾 SPRT + 路径 DP，继续按 $p_1/\kappa$ 做敏感性；
> 2. **Q2**：16 策略全枚举、吸收检查和稀疏奖励求解；
> 3. **Q3**：65536 固定策略全枚举，不以 GA/SA 替代；
> 4. **Q4-A1**：Q2 用确定性 Beta 求积，Q3 用全策略 CRN/RQMC，统一提供停止价值 $G(s)$；
> 5. **Q4-A3 主求解**：Q2 用 finite-horizon memoized DP 得到给定先验/成本/$H/B$ 下的 exact-to-tolerance 政策；Q3 用成本敏感 KG + rollout，并以 Q2 精确 DP 和独立外层仿真校准；
> 6. **Q4-A2 审计**：固定样本用精确二项联合区间，自适应选择/停止用 simultaneous CS；稳健结果默认报告而非无依据硬约束；
> 7. **停止原则**：最佳追加检测的净价值不再为正即停止；不要求所有参数统一达到某个置信半宽；
> 8. **成本原则**：过去抽样、未来追加抽样、对象切换和生产检测分账，每项只扣一次；
> 9. **结论边界**：题面缺 $(N_j,K_j)$、先验强度和完整抽样成本，所以当前锁定的是政策算法，不能提前宣布一个唯一最优检测次数。

本次 Q4 模型—算法同步重构完成。下一实现顺序应为：**Q4 belief/data schema → Q4-A1/Q2 确定性终止价值 → Q4-A3/Q2 精确 DP oracle → Q4-A3/Q3 KG/rollout → Q4-A2 自适应稳健审计 → 阶段4验证清单**。任何旧的“样本给定后只跑后验 MC/稳健搜索”结果只能作为 Q4-M2/M3 子问题结果，不能再代表完整 Q4。
