# 一、问题二（Q2）

## Fig.Q2-1 最优策略期望成本构成图

| 项目 | 内容 |
|---|---|
| 图编号 | Fig.Q2-1 |
| 图名建议 | 问题二最优固定策略的期望成本构成 |
| 核心结论（一句话） | 六种情形下最优策略的成本结构存在明显差异；尤其情形3中，“支付成品检测成本”与“承担市场调换损失”可形成不同成本分担路径，但总成本相同，因此出现并列最优策略。 |
| 图类型 | 分组/堆积柱状图 |
| 现有图 | `q2_optimal_cost_composition` |
| 是否重画 | 建议在现有图基础上优化，不必从零推翻 |
| 数据来源 | `results/q2/best_policies.csv`；必要时辅助读取 `results/q2/summary.json` |
| 优先级 | 必须 |
| 预期位置 | 问题二结果分析 / 结果讨论 |

### 1. 图的论文目的

本图不是只为了比较“哪个情形总成本更高”，而是要解释：

\[
\boxed{\text{最优策略为什么这样选}}
\]

重点突出问题二中的经济权衡：

\[
\boxed{\text{检测成本}\ \text{vs}\ \text{市场调换风险}}
\]

### 2. 横轴建议

建议依次设置为：

- 情形1
- 情形2
- 情形3-A
- 情形3-B
- 情形4
- 情形5
- 情形6

其中必须保留情形3的两个并列最优方案。

### 3. 成本分类要求

现有版本将成本分成：

- 零件采购
- 零件检测
- 装配
- 成品检测
- 拆解与调换

论文版建议改为六类：

1. 采购
2. 零件检测
3. 装配
4. 成品检测
5. 拆解
6. 调换损失

**不要再把“拆解”和“调换损失”合并。**

原因是情形3的解释核心正是：

- 一种并列策略支付成品检测成本；
- 另一种并列策略不检测成品，而承担市场调换损失；
- 两者最终期望总成本相同。

### 4. 标注要求

- 每根柱顶部建议标注对应的**期望利润**；
- 图例必须使用中文；
- 如果使用堆积柱，各成本项应有明显区分；
- 图注中说明核算单位为“最终成功交付一件合格品”；
- 情形3两个方案应明显区分为 3-A、3-B，而不是只写两遍“情形3”。

### 5. 本图应支持的正文结论

> 在不同生产情形下，最优策略对应的成本结构存在显著差异。特别地，在情形3中，一类方案选择支付成品检测成本，另一类方案选择承担市场调换损失，但二者期望总成本相同，从而形成并列最优。

# 二、问题三（Q3）

## Fig.Q3-1 Top 5 可行策略利润及相对最优损失图

| 项目 | 内容 |
|---|---|
| 图编号 | Fig.Q3-1 |
| 图名建议 | 问题三 Top 5 可行策略利润及相对最优损失 |
| 核心结论（一句话） | 最优策略在全部可行固定策略中具有明确利润优势，应同时展示策略利润与其相对最优损失，而不是只展示无解释意义的 Strategy ID。 |
| 图类型 | 横向条形图 / 排名图 |
| 现有图 | `top_policy_profit` |
| 是否重画 | 是，建议重新设计 |
| 数据来源 | `results/q3/top10_policies.csv`，建议只取 Top 5；必要时结合 `results/q3/summary.json` |
| 优先级 | 必须 |
| 预期位置 | 问题三结果分析 |

### 1. 现有图主要问题

现有图存在三个论文表达问题：

1. 标题与坐标轴为英文，与整篇中文论文风格不统一；
2. 横轴只写 `Strategy ID`，如 `63487`、`47103`，评委无法从编号理解策略含义；
3. 柱状图从 0 起画时，57.667 与 55.827 的视觉差异很小，不能突出最优与次优之间真正重要的利润差。

### 2. 新图的核心指标

应对 Top 5 可行策略展示：

- `strategy_id`
- `strategy_bits`
- `expected_profit`
- 相对最优损失

定义：

\[
\Delta \Pi(d)=\Pi^*-\Pi(d)
\]

其中最优策略满足：

\[
\Delta\Pi=0
\]

当前已确认的前两名示例：

\[
63487:\ \Pi=57.6667
\]

\[
47103:\ \Pi=55.8272
\]

因此：

\[
\Delta\Pi\approx1.8395
\]

### 3. 推荐版式

建议使用**横向条形图**。

每条策略标签建议同时显示：

```text
63487
1111111111101111
```

右侧可标注：

```text
利润 57.667
相对损失 0.000
```

对于其余策略则显示相对于最优策略的利润损失。

### 4. 不建议

- 不建议继续画 Top 10，Top 5 已足够；
- 不建议只保留策略编号；
- 不建议继续使用全英文标题；
- 不建议仅画利润柱而不展示相对损失。

### 5. 本图应支持的正文结论

> 在全部可行固定策略中，最优策略 \(63487\) 的期望利润为 57.6667 元，较次优策略高约 1.8395 元，说明其最优性并非数值偶然，而具有明确的利润优势。

## Fig.Q3-2 关键参数敏感性与策略切换图

| 项目 | 内容 |
|---|---|
| 图编号 | Fig.Q3-2 |
| 图名建议 | 问题三关键参数敏感性与策略切换 |
| 核心结论（一句话） | 最优策略对多数参数扰动保持稳定，但部分关键参数变化会触发策略切换，因此应把“具体参数场景—利润间隔—策略是否变化”直接建立可解释映射。 |
| 图类型 | 双面板热力图 / 矩阵图 |
| 现有图 | `sensitivity_profit_gap` |
| 是否重画 | 是，必须重做 |
| 数据来源 | 以 `results/q3/sensitivity.csv` 及后续拆分的缺陷率/成本敏感性结果文件为准 |
| 优先级 | 必须 |
| 预期位置 | 问题三敏感性分析 / 结果讨论 |

### 1. 现有图主要问题

当前旧图横轴只是：

\[
0,1,2,\ldots
\]

即 sensitivity scenario 的序号。

读者无法从图中知道每个点对应哪个参数和哪个取值，只能再查 CSV。

因此现有图更像程序诊断图，而不是论文图。

### 2. 推荐整体结构

建议改为**双面板矩阵图**：

- 左侧：(a) 缺陷率敏感性
- 右侧：(b) 成本压力测试

### 3. 左侧：缺陷率敏感性

#### 行

- \(p_1\)
- \(p_2\)
- \(p_3\)
- \(p_4\)
- \(p_5\)
- \(p_6\)
- \(p_7\)
- \(p_8\)
- \(p_{S1}\)
- \(p_{S2}\)
- \(p_{S3}\)
- \(p_F\)

#### 列

- \(5\%\)
- \(20\%\)

#### 每个格子建议展示

\[
\Delta\Pi=\Pi_{\text{best}}-\Pi_{\text{second}}
\]

可采用：

- 颜色深浅表示 \(\Delta\Pi\)；
- 格子内同时标数字；
- 若该场景下最优策略发生切换，用 `★`、橙框或其他明显符号标出。

#### 重点突出

当前结果中最重要的已知切换场景：

\[
p_F=20\%
\]

此时最优策略切换为：

\[
65535=1111111111111111
\]

即最终成品检测也开启。

### 4. 右侧：成本压力测试

#### 行

建议至少包括：

- 零件检测成本
- 半成品检测成本
- 成品检测成本
- 调换损失
- 半成品拆解成本
- 成品拆解成本

#### 列

- \(-25\%\)
- \(+25\%\)

#### 每个格子

同样展示：

\[
\Delta\Pi=\Pi_{\text{best}}-\Pi_{\text{second}}
\]

若最优策略发生变化，应显著标记。

### 5. 重要表述限制

成本 \(\pm25\%\) 属于**人为设置的压力测试情景**，不能写成真实观测区间或题面给定范围。

缺陷率部分如果采用题面表格中实际出现的 5% / 20%，可以按“已观测参数范围内敏感性”描述。

### 6. 本图应支持的正文结论

> 敏感性分析表明，问题三的最优策略对多数单因素扰动具有较强稳定性；但当最终成品缺陷率升高至 \(20\%\) 时，最优决策切换为全检测策略，说明最终装配质量风险是影响生产决策的重要因素。

# 四、统一制图规范建议

1. 图题、坐标轴、图例统一使用中文；
2. 数字和数学符号可使用英文衬线字体；
3. 优先导出 SVG，同时保留高分辨率 PNG；
4. 保证黑白打印时仍可通过线型、边框、纹理或标注区分信息；
5. 不只依赖颜色表达“最优/切换”等关键信息；
6. 图中策略位串必须与代码规定的变量顺序一致；
7. 图内不写超过证据强度的结论，如“全局最优”；
8. 所有正式数值直接读取仓库结果文件，不手工复制后重新计算；
9. 若结果文件更新，应先确认 source SHA / commit，再重新生成图。
